compiler stages
parsing - turn raw code into abstract representation
transformation - manipulate abstract representation to do what compiler wants
code generation - create new code

lexical and syntactic analysis
    lexical analysis - lexer
        character stream and raw code converted into a stream of tokens
        tokens are objects, describing an isolated piece of syntax

    syntactic analysis - parser
        sequences of tokens are validated
        token sequences reformated into an abstract syntax tree
        AST describes relation of tokens to one another 
        parser builds an AST

transformation
manipualtes AST from syntactic analysis step- can interpret or create new code
AST has AST nodes
    nodes have defined properties describing specific language components
    e.g expressions, literals, etc

    can manipulate nodes by adding/removing/replacing

    can mainupate AST in same language or translate to a new language

in project we are creating a new AST for target language - C 

traversal
    traversal process goes through nodes of AST depth first wise

visitor
    object to perform action for specific node types during tree traversal

code generation
    AST converted to code or intermediate representation

    cannot hold pointer to itself
